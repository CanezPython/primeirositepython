# Transformando conhecimento em algo real

Este site nasceu de uma necessidade prática: criar meu próprio portfólio.

Eu poderia simplesmente contratar alguém ou utilizar uma plataforma pronta. Mas percebi que existia uma oportunidade muito mais interessante: aproveitar essa necessidade como um projeto de aprendizagem.

A proposta passou a ser simples:
aprender programação criando algo que realmente tivesse utilidade.

Escolhi o Python como ponto central desse projeto e utilizei suas bibliotecas e recursos para construir o site. A intenção não era apenas chegar ao resultado final, mas compreender cada etapa do processo.

Por isso, este projeto representa somente o começo de um estudante de programação que queria somente criar um portfólio audiovisual.

Ele é também um registro da minha evolução.

Cada página, cada função e cada detalhe fazem parte desse processo de aprendizado. O resultado talvez ainda esteja longe de ser perfeito — e isso faz parte da proposta.

Este é um projeto real, construído por alguém que está aprendendo e que decidiu transformar esse aprendizado em algo concreto.
