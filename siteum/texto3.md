# Construindo meu primeiro site

Construir este primeiro site foi, acima de tudo, uma experiência de aprendizado.

Decidi desenvolver todo o projeto em Linux Mint, utilizando o VS Code, Python 3 e suas bibliotecas. Fazer dessa maneira foi uma escolha pessoal, mas também uma oportunidade de conhecer melhor o ambiente de desenvolvimento e entender todo o processo por trás da aplicação.

Segui passo a passo as orientações do curso e digitei linha por linha do código, procurando não apenas reproduzir o que estava sendo ensinado, mas entender o motivo de cada comando e de cada estrutura.
Durante o processo, vieram os desafios.

Erros de código, dúvidas, testes, ajustes e aquela satisfação especial de descobrir por que algo não estava funcionando.
E talvez essa seja uma das partes mais interessantes de aprender programação: perceber que um erro não significa que você fracassou. Significa que existe alguma coisa para descobrir.

Aos poucos, aquilo que começou como algumas linhas de código foi se transformando em uma aplicação funcionando.
E quando finalmente vi o site pronto, percebi que o projeto representava muito mais do que uma página na internet.
Representava uma volta.

Uma volta à programação, à curiosidade e à vontade de construir coisas.
Este é meu primeiro site em Python.
Não é o ponto final.

É o começo de uma nova etapa.
